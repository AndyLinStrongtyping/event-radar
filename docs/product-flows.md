# 產品流程與內容生命週期

2026-10-25｜[產品規格](product-prd.md) · [使用案例與驗收](product-stories.md)。本頁是使用者與營運流程；技術實作圖仍見 [architecture](architecture.md)。虛線表示規劃中的展品文章，不代表已存在頁面。

## 訪客主流程

```mermaid
flowchart TD
  A[首頁] --> B[找展覽：城市／館別／展名／日期]
  B --> C{查詢結果}
  C -->|有資料| D[展期、地點、來源與票務]
  C -->|零筆| E[說明收錄範圍、調整條件]
  C -->|請求失敗| F[顯示錯誤、重試]
  D --> G[官方網站核對／購票]
  A --> H[海洋／化石主題頁]
  A --> I[館所介紹]
  H --> I
  I --> B
  H -.-> J[展品探索文章：規劃]
  I -.-> J
  J -.-> K[延伸科普與參考來源]
  J -.-> L[相關文章／館所／已核對展覽]
  L -.-> B
```

首頁承擔找展與分流；主題頁承擔分類探索；館所頁承擔行前資訊；文章承擔知識閱讀。沒有確認正在展出的展品，只連館所與科普，不提供虛假的「現在去看」入口。

## 資料更新與站長處理

```mermaid
flowchart TD
  A[已啟用的每週工作] --> B[取得來源]
  B --> C{取得成功？}
  C -->|否| D[判斷可重試／次數上限]
  D -->|可重試| B
  D -->|耗盡或不可重試| E[記錄失敗、保留可用舊資料]
  C -->|是| F[驗證欄位、日期、來源與完整度]
  F -->|通過| G[去重、比較異動、交易保存]
  F -->|內容不足| H[待審]
  F -->|大量縮水或換鍵| I[暫緩完整度判定、人工核對]
  H --> J[站長查看原始資料與官方證據]
  J -->|可證實| K[記錄補正並重跑]
  J -->|不可證實| H
  K --> F
  G --> L[更新工作結果及來源提示]
  E --> M[站長處理原因，再授權重跑]
```

這是目標行為；國美館個別逾時保留、科博館重試及場次待核對持續性目前有 [已知缺陷](review-2026-10-25-non-seo.md)，不能把流程圖當成已全部驗證。長期待審不因時間自動上架；容量、歸檔與清理依維運規則另行管理，不能在清理時連帶刪除有效資料及必要審查證據。

## 展品文章生命週期（全為規劃）

```mermaid
stateDiagram-v2
  [*] --> 草稿
  草稿 --> 待核對: 內容與來源齊備
  待核對 --> 草稿: 證據不足或圖片條件不清
  待核對 --> 可發布: 事實、圖像、連結通過
  可發布 --> 已發布: 完成發布檢查
  已發布 --> 待修訂: 發現錯誤或新證據
  待修訂 --> 待核對: 完成修訂
  已發布 --> 已撤回: 重大錯誤或素材問題
  已撤回 --> 草稿: 更換內容後重新檢查
```

待修訂的舊版只有在不存在重大誤導時才繼續顯示；重大錯誤先撤回。修訂保留日期、原因與改動範圍。撤回同步移除入口，但不把舊網址導向無關文章；明確說明內容不可用。

## 每週產品改善閉環

檢查同步與網站 → 填寫 [每週成效](weekly-product-review.md) → 分辨真實訪客、站長測試與資料限制 → 選一項問題 → 對應需求與驗收 → 小幅發布 → 下一週比較。以找展、核對與閱讀的實際用途判斷，不只追求停留時間增加。
