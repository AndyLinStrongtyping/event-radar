# Event Radar｜React 考古視覺階段紀錄

核對日期：2026-10-10（臺灣時間）。本階段完成**本機介面改版**，沒有公開部署或啟用線上排程。

## 已完成

- `frontend/` 新增 React + TypeScript + Vite 首頁。`npm start` 與 `npm run preview` 會先建置前端，原有 Node.js API、PostgreSQL 流程與九頁館所介紹繼續使用。
- 視覺以古文明石碑、地層、恐龍化石及博物館檔案為主題。首頁石碑照片由使用者提供；照片只作探索主題示意，不代表奇美館藏。既有館所照片與來源說明保留於各介紹頁。
- 展覽搜尋保留城市／館所連動、關鍵字、展出狀態、明確免費資訊、查詢基準日及測試資料開關；展覽卡可展開館方連結、票價、購票與資料更新資訊。結果採 18 筆一頁的「載入更多」，畫面顯示已載入／總筆數。
- 票務索引可依城市切換；一般入館與特展票價持續分開。館所來源新鮮度和出發前開館提醒仍由既有 API 提供，不增加未經核對的承諾。
- 首次讀取與重新搜尋時出現短暫「發掘文物」過場；系統設定減少動態效果時停止實質動畫。手機排版、鍵盤焦點、圖片替代文字與列印版已配置。

## 本機驗證

- `npm run build:web`：通過。
- `npm run typecheck`：通過。
- `npm test`：29/29 通過。
- `npm run test:integration`：通過，包含 React 首頁與建置資產可載入、奇美介紹頁入口維持可用的契約檢查。
- 瀏覽器實際操作：首頁 25 筆展覽先顯示 18 筆，點「載入更多展覽」後為 25/25；臺南市只列出當地已接入館所；奇美展覽檔案能展開核對一般票與特展票；票務索引選臺北市只顯示臺北館所。手機視窗無橫向溢出。
- 無資料庫預覽已在瀏覽器載入；分頁 API 指定 `limit=2&offset=2` 回傳 2 筆、總數 10 筆。[新版首頁截圖](screenshots/event-radar-react-hero.jpg)記錄桌面主視覺。
