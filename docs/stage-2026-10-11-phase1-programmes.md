# Phase 1 階段紀錄：奇美活動候選模型與五館待審盤點

核對日：2026-10-11，範圍為**本機** Event Radar。這是 Phase 1 的一個可驗證切片，並非整個 11 階段路線圖完成。

## 已完成

- `expoEvent` 仍與限期特展、常設展分流；本機首頁顯示 10 筆人工更新快照，包含西洋武術工作坊。使用者看得到官網時間原文與逐筆官方連結。
- `db/015_programme_events.sql` 新增候選活動與異動歷史表。手動 `npm run import:chimei:programmes` 用 `(museum_id, provider, source_type, source_event_id)` 識別，交易中判斷內容 hash，僅欄位真的改變才留下歷史。沒有來源缺席自動刪除。
- 時間只對完整明確範圍轉成起迄日；音樂節多場次、工作坊中的售票日、「即日起」、僅有時段等只記分類及原文，不推出錯誤的「展出中」。
- `docs/openapi.yaml` 記錄靜態 `/chimei-activities.json` 的真實回應；整合測試用實際 HTTP 回應驗證。這不是正式活動搜尋 API，也沒有訂閱／通知。

## Phase 1 尚未完成的門檻

1. 奇美 `specialEvent` 候選與既有人工特展的身份及官網詳情再核對；在清單涵蓋、跨週格式與使用條件有證據前，不啟用正式自動來源。
2. 釐清奇美活動的 `location`、`isfree`、`tag` 等原始欄位語意與可用性，再決定是否進共通模型；現階段只保留可核對的最小欄位。
3. 逐筆核對五館待審內容，依館方證據補正或維持隔離；首次 coverage 基準需下一次真實來源工作比較，不能由單日成功宣稱跨週穩定。
4. 尚未開始美術館、表演藝術、深海探勘或國外來源；部署依[新版路線圖](future-roadmap.md#2026-10-11-優先順序取代下方舊版擴館部署順序)排在這些 Domain、測試與文件之後。
