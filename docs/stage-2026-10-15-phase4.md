## 已完成與驗證

- [海生館官方當日節目表](https://www.nmmba.gov.tw/ActiveShow_D_Cus.aspx?n=33D045D1594ED637&sms=00C15C8CDECA96C3)當天列出 9 筆活動；大洋池餵食解說列三個時間。`npm run sync:domain -- --source nmmba` 本機真實同步接受 9 筆、零新增／更新、9 筆未變，`observedOn=2026-10-15`。既有 Adapter 驗證頁面日期、場數、時刻及地點；來源大幅縮水會拒收，公開 API 只顯示最近成功批次。
- [館方服務及票價頁](https://www.nmmba.gov.tw/cp.aspx?n=A6476B49BA86BBD5&s=B3CCAAE6060F5DB7)在 10/15 查到的平常時間為全年 09:00–17:00、週二例行休館；國定假日、連續假期、寒暑假及天候有例外。導覽頁先前的分月時間與目前官網不一致，已修正並標核對日期。
- 新增第 022 migration：`museum_opening_exceptions` 只記**有官方指定日期證據且人工核對**的開／休館與起迄時間；`museum_opening_exception_changes` 留下覆核異動。`review:marine-opening` 本機命令驗證日期、時間、官方 HTTPS 佐證與核對者。相同內容重跑不新增紀錄。
- `/visit-status?museum=nmmba&date=...` 若有逐日核對紀錄，回傳該日 `open`／`closed`、證據網址及核對時間；沒有紀錄仍回 `unknown`，不從「週二通常休館」或當日節目表推定指定日期狀態。React 既有行前提示可直接顯示該回應。
- 單元測試、型別、React build 與隔離 PostgreSQL／真實 HTTP 整合測試驗證開館例外的冪等、無效證據拒收、核對後開館回應及未核對日保持 `unknown`。整合測試的特殊日期與公告網址為**合成資料**，本機正式庫沒有寫入虛構例外。
- 第 023 migration 新增 `marine_daily_observations`：每個成功匯入日保留完整節目清單；同日相同內容重跑更新最後觀察時間，同日內容改變另留版本。匯入與快照同一交易，`SOURCE_ANOMALY` 批次不建立歷史。`/marine-programmes?date=YYYY-MM-DD` 可查指定日最後成功版本，`/marine-observation-days` 列日期與版本數；不帶日期仍是最近一次成功清單。React 深海探勘可切換已保存日期，並對照所選日期與最近成功觀察的節目及時段增減，明示歷史時段不能作為今日或未來保證、缺席也不等於取消。
- 本機第 023 migration 已套用，10/15 再次讀取官方當日表接受 9 筆（全未變），建立該日第一份正式每日快照。70 項單元測試、型別檢查、React build、隔離 PostgreSQL／HTTP 整合測試通過；整合案例以合成日期驗證跨日保留、同日變動兩版、同日重跑不增版、異常批次不留快照、日期查詢與分頁。
