# 2026-10-11｜館所圖鑑九館補圖

React 首頁圖鑑原本只有奇美與科博館卡片有照片。這次讓其餘七館也有對應的館舍或展場照片，九張卡片改為一致的圖文高度。故宮南北院、科工館、海生館重用原本已在導覽使用的照片；臺博館、臺史博、科教館新增 Wikimedia Commons 縮圖。每張卡片有具體的替代文字，圖鑑下方可開啟[照片來源與授權頁](../web/photo-credits.html)。授權、作者及原始檔案逐張記在[圖片來源表](sources.md#常設展照片來源與使用)。

新圖是館舍舊照，不代表當期特展；科工館和海生館的展場照也只代表拍攝時狀態。圖片尺寸為 960px 縮圖，每張約 160–190 KB；原檔不改動，卡片只用 CSS 裁切與色調。網站仍為本機預覽，沒有公開部署。

驗證：React build、型別檢查、48 項單元測試及 PostgreSQL 整合測試通過；本機瀏覽器檢查桌面圖鑑、390px 手機寬度單欄卡片與照片署名頁。3000 埠的首頁、署名頁及三張新增圖片 HTTP 均回應 200；九張卡片的圖片替代文字由瀏覽器可及性樹確認。手機寬度已查看前段與末段卡片，但尚未在實際手機裝置檢查。
