# Phase 3／4 階段紀錄：表演藝術與深海探勘

核對日：2026-10-12（臺灣時間）。本階段只在本機開發與手動執行，不進公開部署。

## Phase 3：臺中國家歌劇院

來源是[館方節目清單](https://www.npac-ntt.org/program/events?place=1)與逐筆節目詳情。清單有「MORE」入口，第一版只讀首頁最多五筆，不宣稱完整。詳情可見同一節目的多個開始時間、廳與購票入口，因此使用 `domain_events → event_sessions`，不把節目塞進單一起迄日的 `exhibitions`。館方頁不是已公開文件化的 API。

本機首次手動同步接受 5 筆節目。來源鍵是官方詳情路徑，重跑相同內容不再新增。場次變動記入 `domain_event_changes`；舊場次若消失只標 `unknown`，不能依缺席推斷取消。解析器目前未建立可靠的逐場售罄、取消、延期判定；`scheduled` 僅指館方列有場次，票務仍須點官方連結。平日／假日票價不同時保留原文，逐場價格範圍為空。

## Phase 4：國立海洋生物博物館

來源是[館方當日活動頁](https://www.nmmba.gov.tw/ActiveShow_D_Cus.aspx?n=33D045D1594ED637&sms=00C15C8CDECA96C3)。第一版要求頁面日期吻合臺灣觀察日、每日場數吻合解析到的時刻數、每張卡有地點，否則停止整批匯入。2026-10-12 本機首次同步接受 9 筆節目。`recurring_schedules` 保留當日觀察到的時段、地點、時長，`observed_on` 避免把舊時段當作未來保證。

[館方服務與票價頁](https://www.nmmba.gov.tw/cp.aspx?n=A6476B49BA86BBD5&s=B3CCAAE6060F5DB7)顯示季節與特殊日開館資訊，但目前沒有可逐日安全判定的資料源。`visit-status` 對海生館仍回 `unknown` 並提供該頁及官網入口，不依節目表推定開館。

## 工程驗證與後續門檻

同日再次手動同步：歌劇院 5 筆皆 `unchanged`、海生館 9 筆皆 `unchanged`，兩者皆零新增、零更新。這驗證同一日相同官網內容的冪等性，尚不能推定跨週穩定。

第 `017_domain_events.sql` migration 已套本機及隔離 PostgreSQL。`npm test` 59 項通過，包含兩個官方格式 adapter 的日期、場數及網址拒收；`npm run typecheck`、`npm run build:web`、`npm run test:integration` 通過。隔離整合測試驗證場次去重、消失場次為 `unknown`、異動紀錄、海生館多時段及時段異動、兩條新 API 真實 HTTP 回應符合 OpenAPI。本機新版 API 回 `performances=5`、`marine-programmes=9`。

React 首頁後續把表演與深海拆成獨立導覽入口。深海入口先以紙色海岸、淺海色與海岸線 SVG 過場，再從水面漸入深藍，以三段下潛旅程呈現節目卡；分段純屬視覺編排，不是館內樓層或生物實際深度。觀察日期與是否為臺灣今日的提醒持續顯示，卡片均連回海生館官網。本機桌面及 390px 手機畫面已核對；設計取捨見[ER-57](technical-decisions.md#er-57深海探勘獨立下潛區塊已實作本機瀏覽器驗證)。

要宣稱 Phase 3 完整，仍需核對 MORE 分頁覆蓋率、館方逐場票務／異動標記及跨日來源穩定。要宣稱 Phase 4 完整，仍需有特殊開館逐日可靠來源、節目跨日追蹤與異常減量判定。兩者目前都沒有排程、Queue、通知或公開部署。
