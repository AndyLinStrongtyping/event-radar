## 產品定義

使用者想知道「目前臺灣有哪些博物館特展、在哪裡、展到何時、值不值得點進去看」。系統必須保留官方連結及來源時間，避免把過期或不確定的資料包裝成最新消息。

## v0.1 功能

1. 以一筆特展對應一個博物館展出檔期；資料包含標題、館別、城市、展區、開始日、結束日、票價備註、短摘要、官方網址、最後查核時間與內容 hash。
2. 匯入同一館的資料可重跑，同一來源識別應對應同一筆展覽；官方更改展期時更新並留下歷史。來源暫時失敗應保留舊資料並記錄失敗；國美館個別詳情失聯目前有[已知缺陷](review-2026-10-25-non-seo.md)，尚不能宣稱完全符合此要求。
3. 依城市、博物館、展名關鍵字、參觀日期範圍查詢；每筆可開啟官方頁面。關鍵字輸入不等於跨城市、館名與全文搜尋。
4. 日期只記**展覽日期**，不把開館時間誤當成展覽起訖時間；休館日、預約與票價細節以官方頁為準。
5. 紹介使用自行撰寫的短摘要與來源連結，不複製館方圖片或長文。

## 非功能需求與限制

- 所有欄位經驗證與參數化 SQL；官方網址只接受 HTTPS 與該館允許的網域。
- 來源狀態分 `curated`（人工整理）、`open_data`（官方公開資料）、`official_page`（館方頁同步）和 `planned`（待介接）。來源出現在清單不代表線上排程已啟用。
- 不自動生成並發布展覽事實。規劃中的展品探索允許 AI 協助整理與示意插畫，但須逐篇核對、標示來源與圖像用途，不能冒充實物或科學證據。
- 每週同步已上線：2026-10-20 科博館、故宮南院、海生館限期展、科工館、國美館及歌劇院六個工作成功，故宮北院獨立關閉。跨週穩定仍待下一次真實排程驗證。現有來源工作佇列具有限重試，但科博館錯誤分類仍有待修問題；多階段佇列、收藏、通知與 AWS 屬後續。
- 科博館個人 API Key 已接入，亦保留公開特展 JSON 路徑；`isSample=true` 的假資料只供測試，API 預設隱藏，不得當成真實展覽。

## 驗收情境

- 奇美「埃及之王：法老」範例可匯入與查詢，顯示館別、臺南市、2026-01-29 至 2027-01-10 和官方連結。
- 同筆重跑不增加總筆數；改展期時 `id` 不變、hash 改變。
- 結束日早於開始日、無效日期、非官方來源網址都被拒絕。
- 查詢預設只顯示當天尚在展期或未來的特展；可以用日期參數查過去資料。
