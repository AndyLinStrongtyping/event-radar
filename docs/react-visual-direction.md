# 未來 React 改版方向

主視覺採「考古發掘未知知識」：訪客像沿著遺址線索前進，從館所、展廳、展件逐層發現故事。色彩可沿用深石綠、砂岩與古銅色；互動重點是清楚的搜尋與來源核對，不讓裝飾遮蔽日期、館別及官方連結。

React 改版時可把館所導覽、展件線索卡、搜尋條件與展覽結果拆成元件，沿用目前 API 與來源標示。先在獨立分支重做前端並逐頁核對，再切換網站入口；不需同時重寫匯入與資料庫。若只是調整靜態內容或樣式，現有 HTML 仍足夠。

展件卡必須保留館方來源與核對日期，並區分原件、復原模型、數位重建、互動展項及可能輪替的藏品。視覺敘事可以像考古，事實描述不可把推測或模型寫成出土原物。照片與館方藏品圖像需確認可使用的授權後再加入。

動畫只輔助揭露內容；鍵盤操作、文字對比、窄螢幕與 reduced motion 都要與桌面版一起完成。
