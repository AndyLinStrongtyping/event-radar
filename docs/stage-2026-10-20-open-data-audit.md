# 2026-10-20 政府開放資料目錄與故宮北院來源核對

## 故宮北院：資料格式穩定，不等於內容完整

政府資料開放平臺[資料集 169167](https://data.gov.tw/dataset/169167)所列「北部院區當期展覽」下載網址，仍是專案現用的 `odapi.npm.gov.tw/data/open/api/v1/exhibition/current.json`；標示「不定期更新」。使用者提供的政府資料集目錄另有北院「展覽回顧」169563，但它是每年更新的歷史資料，不是當期展覽備援。

資料集頁另有提供機關聯絡窗口及回應區，可用兩個明確缺漏的展覽 ID、官網詳情網址、展期與 JSON 取得日期回報內容不同步。2026-10-20 檢視故宮[展覽活動 OpenAPI 文件](https://odapi.npm.gov.tw/data/swagger-ui/index.html?urls.primaryName=%E5%B1%95%E8%A6%BD%E6%B4%BB%E5%8B%95)，此分類只列 `current.json`（當期）及 `past.json`（回顧），沒有另列預告清單接口。正式修復路徑是請資料提供機關核對當期資料完整度及 GitHub Actions 所在環境的連線問題；尚未取得機關答覆，不能視為已解決。

2026-10-20 在本機唯讀取得官方 JSON：HTTP 200、22 筆來源紀錄、1 筆符合現有限期展規則、15 筆待審、6 筆略過。對照館方[當期展覽頁](https://www.npm.gov.tw/Exhibition-Current.aspx?l=1&sno=03000060)、[真知灼見詳情](https://www.npm.gov.tw/Exhibition-Content.aspx?l=1&sno=04014549)與[養心詳情](https://www.npm.gov.tw/Exhibition-Content.aspx?l=1&sno=04014551)，可確認兩檔展期至 2026-12-27 的北院展覽未出現在可公開 JSON 清單。館方[新聞稿](https://south.npm.gov.tw/ActivitiesDetailC006110.aspx?Cond=8cfb1ed5-62e4-4bc6-b812-4081ed548eac)也載有這兩檔展訊。搜尋引擎中的官網頁面可能有快取；它只用來交叉核對，不是自動匯入來源。

本機程式直連 `www.npm.gov.tw` 當期頁回 HTTP 403；2026-10-20 檢視北院預告頁的實際回應，`server: cloudflare`，HTML 標題是 `Attention Required! | Cloudflare`，並明示 `Sorry, you have been blocked`。這能確定請求在網站安全層被拒絕，**不能確定是哪條規則**，也不能推論缺少某個 API Key。GitHub runner 連另一主機 `odapi.npm.gov.tw` 曾逾時，屬不同的連線症狀，不能混為同一根因。不能把當期頁、票務站或搜尋快取直接宣稱為可在雲端穩定抓取的替代來源，也不採用假裝真人瀏覽器、繞過存取限制的做法。南院官網有 RSS 專區，但目前沒有證實北院有可用且完整的展覽 RSS。

補查 RSS 路線：南院[官方 RSS 專區](https://south.npm.gov.tw/Messages/RSS.htm)的「當期展覽」XML 於 2026-10-20 唯讀回 HTTP 200，119 個項目的連結都指向南院網站，標題沒有上述兩檔北院展覽。因此它可作南院線索，不能填補北院清單。使用者提出的北院[展覽預告](https://www.npm.gov.tw/Exhibition-Preview.aspx?sno=03000061&l=1)及[展覽活動行事曆](https://www.npm.gov.tw/Calendar.aspx?sno=02012623&type=1)可作人工交叉核對，但同日程式直連均回 HTTP 403；不能當成已驗證的無人值守來源。另提供的南院[展覽回顧頁](https://south.npm.gov.tw/ExhibitionsListC003110.aspx?appname=Exhibition3113)是歷史展覽，不是北院當期展覽。

新增 `npm run probe:npm-north`：只讀取官方 JSON、統計三種處理狀態，並核對兩筆有明確來源鍵、展名、展期與詳情網址的已知當期展。發現缺漏時退出碼為 1，提醒人工核對。後依使用者決定調整為部分匯入：正式 `--official` 北院匯入仍寫入合格展覽，但標記 `deferred_partial`，不更新完整清單基準，也不依缺席下架舊展。兩筆已核對資料另存 `data/npm-north-verified-supplement.json`，以獨立人工來源匯入；使用前須再核對官網。本段記錄 2026-10-20 的稽核時點；2026-10-21 已完成正式匯入與部署，詳見[上線驗證紀錄](stage-2026-10-21-npm-north-release.md)。`--snapshot` 與人工 `--file` 可供隔離測試或逐筆核對。已知清單於展期結束後自動失效，不能保證其餘所有展覽完整；未來仍須建立可持續的官方清單對照或向資料提供機關確認差異。故宮北院雲端排程開關保持關閉。

故宮[典藏資料檢索 Open Data](https://digitalarchive.npm.gov.tw/opendata/)是**文物典藏及圖像**資料，提供品名、年代、分類與個別文物資訊；它不是「北院當期展覽」清單，沒有可用來判定展期、展廳與展覽異動的完整欄位。其開放宣告對低階文物圖像標示 CC0、對中階圖像及網站文字標示 CC BY 4.0；若日後使用文物圖像，仍需核對每筆素材與標示方式，不可將典藏圖像授權直接套用到展覽海報或其他第三方照片。該站程式直連曾回 403；即使可用也只能作內容／圖片的另一個領域來源，無法解決北院展覽同步。

另據故宮北院主站[政府網站資料開放宣告](https://www.npm.gov.tw/Articles.aspx?l=1&sno=02002157)，官網資料及素材在其有權授權的著作權範圍內，原則上可無償再利用，包括開發產品或服務，使用時須註明出處；商標、機關標誌、個資、第三人權利與個別特別聲明的影音、圖像、文章等不因此一併開放。實際採用展覽圖片前要逐件檢查來源頁有無特別限制，並保留品名／來源／授權核對紀錄。這是**內容再利用授權**，不能解釋為允許繞過 Cloudflare 存取控制，也不保證排程程式能連線取得頁面；網站不得暗示與故宮合作、受其認可或代言。

### 文化部展覽 JSON 實查

[文化部「展覽資訊」資料集](https://data.gov.tw/dataset/6012)的實際 JSON 網址是 `https://cloud.culture.tw/frontsite/trans/SearchShowAction.do?method=doFindTypeJ&category=6`，不是 `https://culture.tw`。2026-10-20 唯讀請求回 HTTP 200、290 筆；以《龍藏經》《養心》《真知灼見》《匯流1950》比對，只有《龍藏經》一筆，且 `sourceWebPromote` 為空，沒有故宮個別詳情網址。它可供跨來源線索與日期比對，但這次不能補齊兩檔已知缺漏，也不能保證故宮北院當期展覽完整。文化部目錄所寫「每日」是資料集更新頻率，不代表每間館都每日提供完整展覽。

### 展覽主題網站與 PDF：可作核對，尚不能取代清單

2026-10-20 透過瀏覽器確認北院[〈物華再現：文物保存修復〉詳情頁](https://www.npm.gov.tw/Exhibition-Content.aspx?sno=04014556&l=1)直接列出展期 `2026-10-08` 至 `2027-01-03`、第一展覽館 105、107 展廳，並連到獨立的[展覽主題網站](https://theme.npm.edu.tw/exh115/CulturalRelicsRenewed/)。主題網站提供介紹與單元內容，但該頁未見展期欄位或 PDF 下載連結。另一檔[〈神獸再現〉主題網站](https://theme.npm.edu.tw/MythicalCreatures115/)則提供「電子摺頁」，下載網址位於 `www.npm.gov.tw/NewFileAtt.ashx`。因此各主題站／PDF 格式與欄位不一致，不能假設每展都有 PDF，或 PDF 都含可機器辨識的展期、地點與更新時間。

PDF 可作已知展覽的**補充核對來源**：先從已驗證的官方列表／詳情取得穩定展覽 ID 與附件連結，才下載 PDF；限制大小與頁數，萃取文字後驗證展名、展期、地點，含歧義或掃描影像則送待審。保留來源 URL、附件雜湊與核對日期；只有經欄位驗證的變動才進異動偵測。PDF 位元組變動不等於展期變更。若主要障礙是 `www.npm.gov.tw` 的 HTTP 403，改抓同主機附件也未證實可解除；主題站能讀到單筆頁面，也不代表存在完整、可排程發現新展的入口。暫不據此啟用北院自動同步。

### 第三方「故宮展覽通」不是可驗證的即時來源

2026-10-20 比對[故宮展覽通](https://museums.qcngt.com/)與[館方當期展覽](https://www.npm.gov.tw/Exhibition-Current.aspx?sno=03000060&l=1)：第三方網站雖標題為「即時查詢」，頁面沒有揭露更新時間或取得資料的方法，當天也未列出館方清單中的〈物華再現〉與〈真知灼見〉等新展，卻仍保存 2025 年展覽紀錄。僅憑畫面不能確定它使用 API、爬蟲或人工維護；不可拿它作北院完整度基準或轉抓來源。館方當期頁在瀏覽器顯示總筆數 19（14 筆當期／長期及 5 筆常設），含展名、展期、展廳及詳情 ID；這證明頁面本身足夠作展覽發現，但尚未證明排程程式可穩定取得其 HTML。先前本機程式直連仍是 Cloudflare 403。

同日測試[官網全站搜尋](https://www.npm.gov.tw/Query.aspx?sno=01000255&l=1)：本機程式以普通 GET 搜尋「真知灼見」仍回 HTTP 403。瀏覽器能打開搜尋頁，但結果區由 Google 自訂搜尋提供，會混合歷史展、主題網站及其他內容；網址 `#gsc.q=...` 是瀏覽器端片段，不會隨 GET 傳給故宮伺服器。搜尋結果可供人工找詳情，不是完整、可核對的當期展覽資料源，也沒有解除主站對排程請求的 403。

進一步以「真知灼見」實查：Google 自訂搜尋前列確實有[故宮展覽主題站](https://theme.npm.edu.tw/exh115/FlashesOfInsight/)，但同批也混入講座、新聞、舊主題站及與展覽無關的 PDF。該主題站有展覽介紹及展件清單，首頁未見完整展期或 PDF；展期仍須由[館方詳情](https://www.npm.gov.tw/Exhibition-Content.aspx?l=1&sno=04014549)核對。故可建立**人工候選線索**流程：以已知展名搜尋 → 僅接受故宮官方網域的主題／詳情連結 → 核對展覽 ID、展期、展廳 → 有館方明確附檔連結時才核對 PDF → 有歧義進待審。不能以搜尋結果數或 PDF 關鍵字推定完整清單、展期或展覽異動。Google [Custom Search JSON API 官方說明](https://developers.google.com/custom-search/v1/overview)目前註明不再開放新客戶，既有客戶亦須於 2027-01-01 前轉換；不應把抓取 Google 搜尋畫面當成穩定、正式的程式資料接口。
