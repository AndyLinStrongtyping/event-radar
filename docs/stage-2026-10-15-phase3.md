# Phase 3｜第一個表演藝術來源：本機功能驗收

核對日：2026-10-15。範圍是臺中國家歌劇院官方 `place=1` 節目清單與各筆詳情；沒有擴稱所有演出場地、所有節目種類或即時售票資料。

## 驗收結果

| 項目 | 實作與證據 |
| --- | --- |
| 多場次模型 | `domain_events → event_sessions`，同節目可有不同時刻、廳、官方購票網址及可空的票價範圍；平假日差異保留原價文字。第 017 migration 與隔離資料庫測試已驗證。 |
| 清單覆蓋 | 官網 `place=1` 的 MORE 在當前 HTML 只是展開預藏卡片，Adapter 讀取所有可辨識詳情，最多 30 筆；改變載入方式或超限便停止。第 018／019 migration 保存清單來源鍵，異常縮水或大幅換鍵需人工覆核。 |
| 冪等與異動 | 來源鍵與場次鍵唯一；重跑相同來源不重複新增，場次內容變更記在 `domain_event_changes`。消失場次只標 `unknown`，不推定取消。 |
| 場次狀態 | 官網按鈕完整明示全節目已額滿／售罄時可標 `sold_out`；部分場次異動公告先把該節目場次設 `unknown`，不進預設未來清單。`review:performance pending|set` 供站長依官網證據逐場核對 `scheduled`、`sold_out`、`cancelled`、`postponed` 或 `unknown`。第 020／021 migration 留證據、核對時間與來源版本，異動歷史留痕。同版同步保留人工結論；來源內容變動使舊結論失效，場次來源消失亦回到 `unknown`。 |
| 公開查詢與畫面 | `/performances` 預設只列最新成功清單內、尚未開始且為 `scheduled`／`sold_out` 的場次；`period=all` 可查舊場次與取消／延期。React 表演區可切換兩種檢視，並連到核對證據與館方頁面。 |

當日新一輪官方清單本機手動同步回 `accepted=20, inserted=0, updated=0, unchanged=20`；本機該來源目前 29 個場次都是 `scheduled`，因此此清單沒有可用於實際寫入的取消或售罄範例。另以唯讀官網請求核對[全節目已額滿頁](https://www.npac-ntt.org/program/events/c-NIh2qmoeYT7)解析為兩個 `sold_out` 場次、[部分場次異動頁](https://www.npac-ntt.org/program/events/c-kboz8xw2UFj)解析為四個 `unknown` 場次；沒有把這兩頁強行加入目前官方清單。

69 項單元測試、型別檢查、React build 與隔離 PostgreSQL／HTTP 整合測試通過。整合案例涵蓋新 migration、同批正常節目照常匯入、未知場次不公開、人工逐場核對、取消場只保留在完整紀錄、證據欄位、重複核對不重複寫入、同版同步保留人工結果與官方內容變動使舊結論失效。所用取消／延期資料是**合成測試資料**，不是宣稱當前官網有這些未來演出異動。

## 持續觀察項目

- 官網目前沒有可安全自動對應**個別場次**的即時餘票結構；`scheduled` 只表示官網列有場次，出發與購票前仍要查館方／售票頁。
- 標題與已確認的「作品簡介」醒目公告可隔離，但館方若變更公告版位，仍須更新 Adapter 與測試。
- 2026-10-14／15 的來源同步提供跨日線索，不能在 10-15 當天聲稱跨週穩定。後續人工同步與來源健康觀察應持續紀錄；依既定順序，部署與 production 排程仍在後面階段。
