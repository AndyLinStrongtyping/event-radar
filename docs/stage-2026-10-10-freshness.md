# 2026-10-10｜來源狀態與發布前核對

這一階段讓訪客知道特展資料是人工核對、近期匯入、同步失敗，或可能過期。`GET /museums` 讀取各館最後成功匯入時間與最近一次同步嘗試，回傳 `dataStatus`。最近失敗優先顯示；無論是否留有同步嘗試紀錄，超過 48 小時沒有成功匯入都提示資料可能過期。近期匯入卻沒有成功的同步嘗試紀錄，只能說明有匯入，不能聲稱已定期同步。

特展頁選館後可看到館別狀態、匯入時間與館方網站入口；混合搜尋結果的卡片也標示各館資料狀態。奇美維持「人工核對」，不因舊匯入時間看起來很近就稱為自動同步；`npm run preview` 的展示資料一律標為「本機快照」。原先常設展入口文字中的「每日更新」也已改掉，避免排程尚未上線時誤導訪客。

本機驗證：`npm test` 26 項通過、`npm run typecheck` 通過、`npm run test:integration` 通過。瀏覽器已核對本機快照及連接 PostgreSQL 的實際頁面，確認奇美與超過 48 小時未匯入的館所顯示相應提示。這些是被動顯示；線上每日同步、主動告警與公開部署仍未啟用。要公開發布，還需可供部署環境連線的 PostgreSQL、受保護的金鑰、排程首跑與監測核對。
