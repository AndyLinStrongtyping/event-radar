# Event Radar｜第二階段紀錄（2026-10-05）

本階段延續[第一階段](stage-2026-10-05.md)的兩項待辦：補故宮北院、海生館導覽，以及建立待審補正和各館暫時性失敗重試。**全部仍是本機成果；沒有 GitHub 遠端、線上排程、Queue 或 AWS。**

## 已完成

- 新增[故宮北院](../web/guides/npm-north.html)及[海生館](../web/guides/nmmba.html)常設展／展區導覽，首頁增設兩個入口，共九頁。兩頁按館方目前展區資訊撰寫，附官方連結、核對日期、展件變動提醒，以及可開地圖的交通入口。此階段沒有加入未核對授權的館方圖片，也沒有把缺迄日的特展資料當作常設展。
- 新增 `review_corrections` 留存展期補正、來源原始內容指紋、原館方網址、證據網址、審查人、備註和建立時間。`npm run review -- --source nmmba` 查看待審；`npm run review:approve -- ...` 留存補正，**下一次匯入同一原始紀錄才套用**。指令只驗證證據為同館官方 HTTPS 網址與日期合法，證據網頁內容仍須人眼核對。
- 補正後的展覽會進搜尋；來源內容或官方連結改變時，舊補正的展覽立即設為不可見，狀態回到待審，直到重新核對。整合測試包含海生館來源改標題、故宮北院來源改連結的情境。
- 新增 `npm run sync -- --source <nmns|npm-south|npm-north|nmmba>`。暫時性網路錯誤、HTTP 429／5xx 才最多重試三次，間隔 30 秒與 2 分鐘；資料格式與驗證錯誤不重試。每日 GitHub Actions 設定檔的四館工作相互獨立，但未在線上啟用，也尚無失敗佇列或 worker。

## 實際驗證

- `npm test`：16/16 通過；`npm run typecheck`：通過；`npm run test:integration`：通過。整合測試使用隔離 PostgreSQL 資料庫，涵蓋匯入回滾、去重、欄位異動、補正留痕、來源變更後停止顯示。重試的錯誤分類由單元測試驗證，**未對真實外部服務做故障注入**。
- 本機資料庫已套用 `db/004_review_corrections.sql`。連本機資料庫的網站於 `http://127.0.0.1:3003/` 供預覽；兩頁已在瀏覽器檢查內容、連結與交通表單呈現。4180 預覽則使用展示資料。
- 本階段未重新量測四個官方資料集的當期筆數；[第一階段的 2026-10-05 實測](stage-2026-10-05.md#本階段已完成)應視為當時快照，不是每日新資料保證。
